# WHSHAM Desktop — نظام إدارة المستودعات المركزي (نسخة سطح مكتب)

نسخة سطح مكتب **محلية بالكامل** (تعمل دون إنترنت) مبنية من الصفر على Electron + React + SQLite.
مشروع جديد بالتوازي مع النسخة السحابية القديمة (المستودع `whsham`) دون المساس بها.

## القرارات المعتمدة
| القرار | الاختيار |
|---|---|
| طبقة البيانات | محلية بالكامل (SQLite) — لا اعتماد على أي خدمة سحابية |
| محرّك الحزم | Electron |
| أسلوب العمل | مشروع جديد نظيف بالتوازي |
| الذكاء الاصطناعي | اختياري (معطَّل افتراضيًا في هذه المرحلة) |
| المستخدمون | جهاز واحد |

## المبدأ الأمني الحاكم
> لا منطق أمني في الواجهة. كل قرار صلاحية يُتخذ في العملية الرئيسية (Main) ويُتحقق منه قبل التنفيذ، وكل عملية حساسة تُسجَّل في سجل تدقيق لا يقبل التعديل.

### ما هو منفَّذ فعليًا في هذه المرحلة
- **عزل كامل للمحتوى**: `contextIsolation: true` · `sandbox: true` · `nodeIntegration: false` · منع التنقّل والنوافذ الجديدة · سياسة CSP.
- **جسر IPC مغلق**: قنوات مُعدَّدة بأسماء صريحة + تحقق `zod` لكل حِمل + خريطة صلاحية لكل قناة + عدم تسريب أي تفاصيل تقنية إلى الواجهة.
- **مصادقة محلية**: تجزئة `scrypt` بملح لكل مستخدم، مقارنة زمنية ثابتة، قفل الحساب بعد 5 محاولات فاشلة (15 دقيقة)، مهلة جلسة خمول، إلزام تغيير كلمة المرور الأولية.
- **صلاحيات (RBAC)**: مصفوفة أدوار/صلاحيات واحدة في `src/shared/permissions.ts`، وإنكار ضمني لأي صلاحية غير مذكورة.
- **سجل تدقيق مُسلسَل**: كل قيد يحمل بصمة القيد السابق (SHA-256)، ويمكن كشف أي تعديل عبر `audit:verify`.
- **قواعد عمل في قاعدة البيانات**: منع الأرصدة السالبة (CHECK + TRIGGER)، وكل حركة إخراج/إدخال داخل معاملة واحدة.
- **FIFO حقيقي**: الإخراج يستهلك الدفعات الأقرب انتهاءً ثم الأقدم استلامًا، ويُرفض كليًا عند نقص الرصيد.
- **تشفير الحقول الحساسة**: AES-256-GCM لِـ«الرقم الوطني» بمفتاح مشتق من سرّ الجهاز المحفوظ بصلاحيات مقيدة.

## البنية
```
src/
  main/        العملية الرئيسية: النافذة، IPC، قاعدة البيانات، الخدمات
    db/        schema.ts (المخطط) · database.ts (الاتصال والتهيئة)
    services/  crypto · auth · audit · inventory
    ipc/       contract.ts (العقد) · register.ts (التسجيل والفحص)
  preload/     الجسر الآمن (contextBridge)
  renderer/    واجهة React (RTL)
  shared/      مصفوفة الصلاحيات والأنواع المشتركة
```

## التشغيل
```bash
npm install
npm run rebuild     # إعادة بناء better-sqlite3 ليطابق إصدار Electron
npm run dev         # تشغيل وضع التطوير
npm run typecheck   # فحص الأنواع (إلزامي قبل أي التزام)
npm run dist        # إنتاج مثبّت Windows (NSIS) في مجلد release/
```

عند أول تشغيل تُنشأ قاعدة البيانات في مجلد بيانات التطبيق، وتُكتب كلمة مرور المدير الأولية في ملف
`first-run-admin-password.txt` داخل المجلد نفسه — يجب تغييرها فور أول دخول ثم حذف الملف.
