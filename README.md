# مستودعات مديرية صحة دمشق المركزية — تطبيق سطح مكتب

**Damascus Health Directorate Central Warehouses** — نظام إدارة مستودعات صحية مركزية، نسخة سطح مكتب
**محلية بالكامل** تعمل دون إنترنت ودون أي خدمة سحابية.

> مشروع مستقل بالتوازي مع النسخة السحابية القديمة (`whsham`) — لا يتشارك معها أي كود أو بيانات.

## القرارات المعتمدة
| القرار | الاختيار |
|---|---|
| طبقة البيانات | محلية بالكامل — `node:sqlite` المدمج (بدون أي وحدة أصلية أو بناء تجميعي) |
| محرّك الحزم | Electron **44.3.0** (وقت التشغيل مُتاح محليًا في `offline-build-tools`) |
| أسلوب العمل | مشروع جديد نظيف بالتوازي |
| الذكاء الاصطناعي | مستبعَد من هذه النسخة |
| المستخدمون | جهاز واحد — نسخة واحدة فقط من التطبيق تعمل في الوقت نفسه |

## المبدأ الأمني الحاكم
> لا منطق أمني في الواجهة. كل قرار صلاحية يُتخذ في العملية الرئيسية ويُتحقق منه قبل التنفيذ، وكل عملية حساسة تُسجَّل في سجل تدقيق إضافة-فقط.

| المجال | التنفيذ |
|---|---|
| عزل المحتوى | `contextIsolation` · `sandbox` · `nodeIntegration: false` · CSP · منع التنقّل وفتح نوافذ |
| جسر IPC | 42 قناة مُعدَّدة بأسماء صريحة (لا تمرير عام) + تحقق `zod` لكل حِمل + خريطة صلاحية لكل قناة + عدم تسريب أي تفاصيل تقنية |
| المصادقة | `scrypt` بملح لكل مستخدم · مقارنة زمنية ثابتة · قفل بعد 5 محاولات (15 دقيقة) · مهلة جلسة خمول · إلزام تغيير كلمة المرور الأولى |
| الصلاحيات | 8 أدوار × 25 صلاحية في مصدر واحد · **إنكار ضمني** · حماية آخر مدير نظام · تسجيل كل محاولة مرفوضة |
| التدقيق | منع الحذف على مستوى القاعدة (TRIGGER) + سلسلة بصمات SHA-256 + زر تحقق يكشف أي تعديل |
| قاعدة البيانات | قيود `CHECK`/`TRIGGER` تمنع الأرصدة السالبة · كل حركة داخل معاملة واحدة · فرض الإغلاق المالي |
| المخزون | FIFO حقيقي (الأقرب انتهاءً ثم الأقدم) · نقل يحافظ على الدفعات وتواريخ الصلاحية · تسوية جرد بفرق صريح |
| البيانات الشخصية | الرقم الوطني مشفَّر AES-256-GCM بمفتاح محلي مُقيَّد الصلاحيات · الكشف يتطلب صلاحية ويُسجَّل |
| التشغيل | سجل تشخيص محلي `diagnostics.log` · نسخ احتياطي بفحص سلامة + نسخة أمان قبل الاستعادة |

## الوحدات
- **التشغيل:** لوحة معلومات · مخزون وحركات (إدخال / إخراج FIFO / نقل / إتلاف / تسوية) · مسح باركود · عهد شخصية (تسجيل، إرجاع، كشف رقم وطني) · تعميمات وتنبيهات.
- **البيانات:** كتالوج المواد · المستودعات · المورّدون.
- **المتابعة:** 6 تقارير (أرصدة · حركات · تحت الحد الأدنى · قرب الانتهاء · عهد مفتوحة · سجل التدقيق) مع تصدير CSV متوافق مع Excel · سجل تدقيق مع فحص سلامة السلسلة.
- **الإدارة:** المستخدمون والأدوار ومصفوفة الصلاحيات · النسخ الاحتياطي والاستعادة · إعدادات الجهة والإغلاق المالي.

## البنية
```
src/
  shared/      مصفوفة الأدوار والصلاحيات والثوابت (مصدر الحقيقة الوحيد)
  main/        العملية الرئيسية
    db/        schema.ts (المخطط) · sqlite.ts (كاشف node:sqlite) · database.ts (التهيئة والبيانات المرجعية)
    services/  crypto · audit · auth · users · catalog · inventory · custody · reports · backup · notices · settings
    ipc/       contract.ts (العقد والتحقق) · register.ts (التسجيل وفحص الصلاحيات)
  preload/     الجسر الآمن (contextBridge)
  renderer/    واجهة React عربية RTL (screens/ + panels/ + components/)
tests/         core.test.ts (وحدات) · scenario.e2e.ts (سيناريو كامل على قاعدة على القرص)
scripts/       setup-electron.mjs (تركيب وقت التشغيل محليًا دون إنترنت)
```

## التشغيل والتحقق
```bash
npm install --ignore-scripts          # لا يُنزَّل وقت تشغيل Electron من الشبكة
npm run setup:electron                # استخراج وقت التشغيل من offline-build-tools محليًا
npm run dev                           # تشغيل وضع التطوير
npm run verify                        # فحص الأنواع + اختبارات الوحدات + السيناريو الكامل + البناء
npm run dist                          # مثبّت NSIS (يحتاج أداة electron-builder مرة واحدة مع اتصال)
```

### نسخة محمولة تعمل دون تثبيت (portable)
تُبنى من وقت التشغيل المحلي + مخرجات البناء داخل `resources/app` — بلا أي تنزيل:
```
release/portable/WHSHAM-Central-Warehouses.exe
```
عند أول تشغيل تُكتب كلمة مرور المدير الأولية في `first-run-admin-password.txt` داخل مجلد بيانات التطبيق، ويجب تغييرها فورًا.

## ما تبقّى (اختياري، لا يعطّل الاستخدام)
- أيقونات وهوية بصرية رسمية للحزمة + ترويسة تقارير A4 وملصقات باركود للطباعة.
- تشفير ملف القاعدة بالكامل (SQLCipher) — يتطلب بناءً أصليًا مخصصًا.
- كشوف الجرد السنوي وكشوف التسليم الموقّعة القابلة للطباعة.
- توقيع رقمي لحزمة التثبيت إن لزم التوزيع خارج نطاق الجهة.
